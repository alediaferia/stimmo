{% trans %}What OMI is, and how to read it{% endtrans %}

{% trans %}OMI is the Osservatorio del Mercato Immobiliare of the Agenzia delle Entrate. Twice a year it publishes, for every microzone of the comune, a minimum and a maximum €/m² value for each property type and state of repair.{% endtrans %} {{ _("The figures on this page are the residential (\"abitazioni civili\") band for %(sem)s.") % {"sem": _sem} }}

{% trans %}Read the band as a range, not a price. The minimum and maximum bracket what an ordinary property of that type in that zone is worth; a specific flat can sit outside it because of floor, condition, outdoor space or finishes.{% endtrans %}

{% trans %}Zones are grouped by fascia: B central, C semi-central, D peripheral, E suburban, R outlying.{% endtrans %} {{ _("%(quoted)s of Milan's %(total)s OMI zones have a residential quotation this semester; a zone with none is shown without a band rather than with an invented one.") % {"quoted": quoted_zone_count, "total": zone_count} }}
