{% trans %}The pipeline{% endtrans %}

§ {% trans %}Address → verdict · 6 steps{% endtrans %}
  1. 01

    {% trans %}Geocode{% endtrans %}

    {% trans %}OSM Nominatim resolves the address to lat / lon. Queries are restricted to Milano comune.{% endtrans %}

  2. 02

    {% trans %}Locate the OMI zone{% endtrans %}

    {% trans %}Point-in-polygon against Milano's official OMI microzone shapes.{% endtrans %}

  3. 03

    {% trans %}Pull the €/m² band{% endtrans %}

    {% trans %}Compr_min – Compr_max for that zone × property type × condition bucket.{% endtrans %}

  4. 04

    {% trans %}Count amenities{% endtrans %}

    {% trans %}OSM Overpass — schools, transit, markets, pharmacies, parks within 500 m.{% endtrans %}

  5. 05

    {% trans %}Adjust the band{% endtrans %}

    {% trans %}A single coefficients table multiplies floor, lift, size, condition, energy, outdoor, era, orientation, exposure, room density, second bathroom, parking box, and amenities.{% endtrans %}

  6. 06

    {% trans %}Classify{% endtrans %}

    {% trans %}Compare asking price to an ask-shifted band (rogito + 6 %). ±5 % around it is fair.{% endtrans %}

Principle · 01

{% trans %}No machine learning.{% endtrans %}

{% trans %}stimmo has no trained model. The entire tuning surface is a single file — valuation/adjustments.py. Every multiplier (floor, lift, size, condition, energy, outdoor, era, orientation, exposure, room density, second bathroom, parking box, and amenities) lives there in plain Python.{% endtrans %}

{% trans %}The verdict is deterministic: same inputs, same output. If you disagree with a coefficient, you can read the line where it lives, change it, and re-run.{% endtrans %}

valuation/adjustments.py → valuation/engine.py → verdict.classify()
Principle · 02

{% trans %}Ask-shifted, not rogito.{% endtrans %}

{% trans %}OMI publishes transacted prices — what changed hands at the notary, after negotiation. In Milano, asking prices typically run 5–10 % above the eventual sale price.{% endtrans %}

OMI rogito
€ 6 090 € 7 560 / m²
+ 6 % ask
€ 6 456 € 8 014 / m²
shift +6 %

{% trans %}We shift the OMI band upward by a fixed +6 % ask-premium before classifying. ±5 % around the shifted band is "fair". The constant lives in verdict.py::ASK_PREMIUM_PCT.{% endtrans %}

{% trans %}What stimmo doesn't model{% endtrans %}

×

Spese condominiali

{% trans %}Routine condominium fees and extraordinary works (lavori straordinari deliberati). Can shift true cost €10–50 k. Invisible to OMI.{% endtrans %}

×

Piano nobile

{% trans %}The classic 1° piano premium in storied buildings. Inside the same building, can drive ±5–10 %.{% endtrans %}

×

{% trans %}Street noise & view{% endtrans %}

{% trans %}A unit on a quiet cortile vs. one on Corso Buenos Aires. OMI averages, doesn't see this.{% endtrans %}

×

{% trans %}Comparable listings{% endtrans %}

{% trans %}Italian per-transaction sale data isn't public. We don't fit a model on stale asking prices — by design.{% endtrans %}

×

{% trans %}Metropolitan belt{% endtrans %}

{% trans %}Sesto, Cinisello, Cologno, Rho — outside the Milano comune polygon. Will fail with "outside Milano".{% endtrans %}

×

{% trans %}Commercial property{% endtrans %}

{% trans %}Shops, offices, ateliers — different OMI category, different dynamics. Residential subtypes only.{% endtrans %}
